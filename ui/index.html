Connect a Kubernetes cluster

Pick a connected cluster, or add one. The tool runs outside your cluster and needs only read-only access.

ⓘLeast-privilege: only read (list/get) on namespaces, deployments, pods, and nodes. Credentials are stored as a k8s Secret reference — never the raw kubeconfig/token.

Select pods

Choose which workloads to consider for network-call analysis. Unselected apps are excluded from the latency map. DaemonSets are auto-excluded (they already run on every node).

Node groupings

These are the detected low-latency islands. Each large orb is a group of nodes close together in the network — replicating a service into any one node per island is enough. Inside each island, every mini-orb is a node, sized by its total traffic; click a node to list the workloads running on it. (Node-level is the granularity replication decisions are made at.)

island = node group mini-orb = node (size = total traffic) click a node to list its workloads · “ratio” = intra/inter latency, lower = cleaner island
